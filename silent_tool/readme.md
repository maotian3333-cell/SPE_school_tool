# 安靜小白板 Quiet Board

教室用的互動小白板：寫便利貼、計時，背景是手繪風的動物場景。
**教室安靜時，動物會出現、上色、到處走動；持續吵雜時，畫面會慢慢褪成灰色、動物停住並淡出。**

- 純 HTML / CSS / JS，單一檔案，無需安裝、無需後端，**聲音只在瀏覽器內分析，不會錄音、不會上傳**。
- 內建場景：🐹 天竺鼠的家、🐄 小農場、🐠 海洋世界、🌲 寧靜森林、🚀 太空漫遊、🌅 日出、☁️ 雲上的鳥（可自行擴充）。

## 部署到 GitHub Pages
1. 新增 repository，把 `index.html` 上傳到根目錄（也可一起放 `README.md`、`custom-scenes.js`）。
2. Settings → Pages → Branch 選 `main` / `(root)` → Save。
3. 打開 `https://你的帳號.github.io/repo名稱/`。（GitHub Pages 是 https，麥克風才能使用。）

## 功能
| 功能 | 說明 |
|---|---|
| 便利貼 | 橫式、可拖曳、可縮放、可換色（標題列的色點）、可調字體大小；內容自動存在瀏覽器 |
| 計時器 | 倒數、快速預設、±1 分、暫停、時間到柔和提示音；可拖曳 |
| 安靜門檻 | 低於門檻（約 dB）才算安靜；可用「以目前環境音設定門檻」快速校正 |
| 反應時間 | 「持續吵雜多久才變單調」「持續安靜多久才恢復」，單位可選**秒／分鐘**；短暫的突然大叫不會有反應，斷斷續續的吵雜會慢慢累積 |
| 活躍度 | 移動速度、物種多樣性、數量 |
| 預覽模式 | 不用麥克風也能強制預覽「安靜／吵雜」畫面 |
| 隱藏介面 | 按 `H` 隱藏所有按鈕與設定（避免學生看到即時音量） |

> dB 為相對值（依電腦麥克風不同）。若同學小聲就超標，請調「麥克風校正」或重新用「以目前環境音設定門檻」。

## 新增自己的場景
1. 把 `custom-scenes.example.js` 改名為 `custom-scenes.js`，放在 `index.html` 旁邊（會自動載入）。
2. 用 `registerScene({ id, name, sky, decor, species })` 註冊；物種 `species` 的繪製函式範例請見檔案內註解。
3. 也可以直接重用內建物種：`Lib.guineaPig, Lib.butterfly, Lib.sparrow, Lib.fish, Lib.jelly ...`。

風格小撇步：形狀請保持圓潤簡單、用乾淨的純色（主程式會自動稍微提高飽和度）。

## 圖鑑與「安靜收集」
- 每個場景有 **10～13 種**動物或物品（天竺鼠 10、農場 12、海洋 13、森林 13、太空 11、日出 10、雲上的鳥 11）。
- 一開始每個場景只有 2 種起始物種。**連續保持安靜 3～5 分鐘（可在設定調整，每次隨機）**，就會有一種尚未收集的新物種隨機來訪：畫面泛起水波、出現新朋友，並收進圖鑑。
- 持續吵雜（達到「持續吵雜多久」設定）會讓安靜計時歸零；需啟用麥克風並使用「自動」模式才會累積。設定裡有「測試：立刻讓下一位新朋友出現」按鈕方便預覽。
- 沒遇過的物種在圖鑑裡是灰色「？？？」剪影，遇到才顯示。圖鑑可設定「保持開啟」，也可重設。
- 「同時出現的種類上限」只會顯示已收集到的物種；自訂場景的 `species` 清單前 2 種是起始物種。

## 轉場動畫
切換場景、開啟／關閉場景選單時，會有「水滴落下、墨汁暈開」的水彩轉場；圖鑑、計時器、便利貼、收納盤出現時有水彩化開動畫；新朋友來訪時畫面上會泛起水波墨點。

## 便利貼（可預先準備）
- **🗂 便利貼收納盤**：可以先打好很多張，不用上課時才現打。每張可選 👁 顯示在白板、－ 縮小成標籤、📥 收起。可「全部顯示／縮小／收起」與「整理排列」。
- 白板上的每張便利貼可**分別**：拖曳、縮放、換色、調字體大小、－ 縮小成標籤（雙擊標籤展開）、⤢ 放大投影（按 `Esc` 或點背景還原）、📥 收回收納盤。
- 便利貼存在這台電腦的瀏覽器裡；要換電腦請用收納盤的「匯出備份／匯入」。

## 選擇場景（關卡介面）
- 工具列「🗺 場景」或設定裡的「選擇場景」會開啟全螢幕的關卡選擇畫面，每張卡片是該場景的預覽圖，並顯示圖鑑收集進度與星星（有收集 ★、過半 ★★、全收集 ★★★）。
- 點卡片即可切換，按 `Esc` 關閉。自訂場景會自動出現在關卡裡。

## 畫風：圓潤的扁平插畫（Flat Illustration）
- 物件簡化成圓潤的基本形狀與純色色塊，沒有透視與光影；大塊色面只有極淡的上亮下深漸層，整體疊一層很淡的噪點紙感。
- 邊界俐落：形狀之間用「同色系稍深的細邊」分開，細節（腿、鬚、草、柵欄）用粗細一致、圓頭的線。
- 七個場景的背景與角色已統一為同一套莫蘭迪色調的扁平畫法：無描邊、無漸層暈染、色塊邊界清晰、五官只用簡單橢圓眼與一道微笑弧線。
- 自訂場景可使用：`shape()`、`line(g,W,點,R,false,粗細,顏色)`、`blob()`、`poly()`（建築，直邊）、`drawTree()`（松樹／圓樹）、`drawCloud()`、`landPts()`（大地形：`shape(g, W, landPts(上緣點, 畫面高度), 顏色, R, { top: 上緣點數 })`）、`rr()`（圓角矩形路徑）、`punch()`（提高飽和度）。

## 風格規格（新增場景／物種時照這份做）
- **造型**：圓潤基本形狀（橢圓、圓角多邊形）組成，細節只留最必要的（眼、嘴、腮紅、一兩個花紋）。
- **色彩**：莫蘭迪低飽和；一個場景只用 5～6 個主色；顏色一律寫 6 位數 hex（例如 `#ffffff`，不要寫 `#fff`）。
- **線條與邊界**：不描邊、不暈染、不用漸層；色塊邊界清晰；線條粗細一致、圓頭。
- **五官**：眼睛為深色橢圓，嘴巴為一道微笑弧線，腮紅為淡粉橢圓。
- **不要**：水彩、鉛筆線、粗細不一或不封閉的線、邊緣積色、手繪抖動。
- **大小比例**：在 `index.html` 的 `TUNE` 表為每個場景設定每種物件的實際寬度（px）；落葉、果實等會下落的物件可用 `band`／`wrap` 限制高度範圍；`exclusive` 可設定不同時出現的物種（如風箏與天燈）。
